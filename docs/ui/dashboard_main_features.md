# Viewzenix1 Dashboard User Guide

## Overview

The Viewzenix1 Dashboard is the central control panel for managing your trading activities. This comprehensive interface provides real-time visibility into orders, trading history, and risk management settings.

## Accessing the Dashboard

The dashboard is accessible at the root URL of the application after logging in. The interface automatically adapts to your device's screen size for optimal viewing on desktop, tablet, or mobile devices.

## Main Navigation

The dashboard includes the following main navigation sections:

- **Home**: Overview and summary statistics
- **Orders**: Real-time order tracking and history (See [Order Tracking Documentation](./dashboard_order_tracking.md))
- **Trading**: Manual order creation and strategy management
- **Risk Management**: Configure risk parameters and protection settings
- **Analytics**: Performance metrics and trading statistics
- **Settings**: User preferences and account settings

## Key Features

### 1. Dashboard Home

The home screen provides:

- **Account Summary**: Current balance, equity, margin usage
- **Active Orders**: Quick view of open orders
- **Recent Trades**: List of recently executed trades
- **Performance Metrics**: Daily/weekly P&L charts
- **System Notifications**: Important alerts and announcements

### 2. Orders Section

The Orders section offers comprehensive order management:

- **Real-time Order Tracking**: Live status updates for all orders
- **Order History**: Searchable historical order database
- **Detailed Order Information**: Complete order specifications and execution details

For complete details, see the [Order Tracking Documentation](./dashboard_order_tracking.md).

### 3. Risk Management Section

The Risk Management interface allows configuration of:

- **Global Risk Parameters**: Maximum drawdown, position size limits
- **Per-Strategy Settings**: Strategy-specific risk controls
- **Stop-Loss/Take-Profit Defaults**: Default protection settings
- **Risk Visualization**: Visual indicators of current risk exposure

## UI Components

### Data Tables

Most data in the dashboard is presented in interactive tables that support:

- **Sorting**: Click column headers to sort data
- **Filtering**: Use filter controls above tables to narrow results
- **Pagination**: Navigate through multiple pages of results
- **Export**: Download data in CSV or Excel format

### Charts and Visualizations

The dashboard includes various visualizations:

- **Performance Charts**: Line and bar charts showing P&L over time
- **Distribution Graphs**: Analysis of trade outcomes
- **Risk Indicators**: Visual gauges for risk exposure

### Forms and Configuration

Configuration sections use standardized form components:

- **Input Validation**: Real-time validation of entered values
- **Tooltips**: Contextual help for complex settings
- **Save/Cancel Controls**: Clear action buttons for configuration changes

## Responsive Behavior

The dashboard adapts to different screen sizes with these modifications:

- **Desktop**: Full layout with all columns and details visible
- **Tablet**: Condensed tables with expandable rows for details
- **Mobile**: Card-based layouts, collapsed navigation, touch-optimized controls

## Keyboard Shortcuts

Power users can utilize keyboard shortcuts:

- **R**: Refresh current view
- **F**: Open filter panel
- **ESC**: Close modals
- **Arrow Keys**: Navigate between table rows when focused
- **Enter**: Open selected item details

## Notifications

The dashboard includes a notification system that alerts you to:

- **Order Status Changes**: Updates when orders are filled, rejected, etc.
- **Risk Warnings**: Alerts when approaching risk limits
- **System Messages**: Maintenance notifications, feature updates

## Troubleshooting

If you encounter issues with the dashboard:

1. **Check Connection Status**: Verify the connection indicator shows "Connected"
2. **Refresh Data**: Use the refresh button to manually update data
3. **Clear Cache**: Log out and back in to reset local data cache
4. **Contact Support**: Use the Help button to reach customer support
